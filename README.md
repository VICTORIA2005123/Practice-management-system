# Practice management system for small CA firms

Final-year project (01CT3801), Department of Information and Communication Technology, Marwadi University.

A keyboard-first practice management system for small chartered accountant's firms. It creates recurring compliance work (GST, TDS, income tax) by itself, tracks who holds each task, warns before digital signature certificates expire, and keeps an audit trail of every change.
